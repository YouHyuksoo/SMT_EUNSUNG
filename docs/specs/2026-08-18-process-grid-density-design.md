# 공정관리 그리드 밀도 조정 설계

## 목표

공정관리 상단 공정마스터 그리드의 불필요한 외곽 여백을 줄이고, 하단 배치 설비 영역의 건수를 제목 줄에 통합해 화면 밀도를 높인다.

## 상단 공정마스터

- `ProcessList`의 `Card` 기본 `lg` 패딩(32px)을 사용하지 않는다.
- 카드 자체는 `padding="none"`으로 두고 `CardContent`에 좌우 16px(`px-4`), 위아래 12px(`py-3`)을 적용한다.
- DataGrid 툴바의 공정 추가 버튼, 옵션 버튼, 그리드 구성과 동작은 유지한다.
- 외곽 카드의 테두리, 모서리, 배경은 유지한다.

## 하단 배치 설비

- 기존 두 줄 헤더를 한 줄로 정리한다.
- 표시 순서는 `배치된 설비 - 공정코드 (공정명) · N건`으로 한다.
- 건수는 공정 정보 뒤에 배치하고 `text-text-muted font-normal` 계열의 보조 표현을 사용한다.
- 제목 아래의 별도 건수 문단은 제거한다.
- 설비 배치 버튼 위치와 동작은 유지한다.

## 데이터·오류 처리

데이터 조회, 선택 상태, 설비 배치·해제, 공정 CRUD 및 오류 처리는 변경하지 않는다. 건수는 현재와 동일하게 `equipments.length`를 사용한다.

## 검증

- 구조 테스트에서 `ProcessList`가 `padding="none"`과 `px-4 py-3`을 사용하는지 확인한다.
- 구조 테스트에서 하단 건수가 공정명 뒤 같은 제목 줄에 렌더링되고, 별도 건수 문단이 제거됐는지 확인한다.
- 기존 상하 60:40 배치와 등록 패널·설비 배치 모달 특성 테스트를 유지한다.
- 프론트엔드 focused 테스트, 전체 구조 테스트, typecheck를 실행한다.
- 사용자가 기동한 dev 서버가 있으면 실제 여백과 한 줄 제목을 렌더 화면에서 확인한다.

## 비범위

- DataGrid 공용 툴바 또는 `Card` 공용 컴포넌트 변경
- 상하 60:40 높이 비율 변경
- 등록·수정 패널, 설비 배치 모달, API 또는 DB 변경
