# 다중입력 통신 결과 미확정 잠금 해제

## 사용자 승인

사용자가 전체 대상 상태 재조회 성공 후 `현재 상태 확인 완료` 버튼으로 잠금을 해제하는 방식을 승인했다.

- 원래 요청 성공을 추정하거나 재전송하지 않는다.
- 현재 pending 요청의 모든 라인에 대한 GET 상태 재조회가 성공해야 버튼을 활성화한다.
- 조회 중, 일부 실패, 미조회, 오프라인, 제출 중, 조직/사용자 변경 및 오래된 조회 응답에서는 활성화하지 않는다.
- 사용자 확인 시 durable pending 저장소 삭제를 먼저 성공시킨 다음 메모리 잠금을 해제한다. 저장소 삭제 실패는 오류를 표시하고 잠금을 유지한다.
- 최신 조회 결과를 라인 선택 상태에 반영하고 기존 선택을 비운다. 이후 현재 상태에 맞는 대상을 새로 선택한다.
- 이전 요청을 성공 처리하지 않는다. 필요하면 확인 완료 사실만 중립적으로 알린다.
- 새 API/DB 변경 없음. 기존 10인치/7인치 레이아웃과 다국어 규칙 유지.

## 완료 기준

- 전체 조회 성공/일부 실패/미조회/조회 중의 버튼 가능 여부 회귀 테스트.
- pending/인증 컨텍스트 변경 후 늦은 응답이 버튼을 활성화하지 않도록 검증.
- 저장소 삭제 실패 시 잠금 유지, 성공 시 선택 초기화 및 최신 상태 반영, POST 없음 검증.
- 프론트 집중 테스트 및 typecheck 수행. 인증 렌더 검증 가능 여부는 별도 기록.
