# 공정관리 그리드 높이 및 설비배치 버튼 설계

## 목적

공정관리 화면에서 하단 배치 설비 목록의 가시 행 수를 늘리고, 상·하단 그리드의 주요 추가 동작 버튼을 같은 규격으로 통일한다.

## 변경 설계

- 현재 상단 공정마스터 60%, 하단 설비배치 40% 비율을 각각 4%p 조정해 56%와 44%로 변경한다.
- CSS Grid 비율은 `14fr:11fr`로 표현해 전체 가용 높이와 기존 `gap-6` 안에서 56:44 비율을 유지한다.
- 하단 최소 높이 `220px`와 각 영역의 overflow 제약은 유지한다.
- 설비배치 버튼은 상단 공정추가 버튼과 동일하게 `Button size="sm"`과 `Plus` 아이콘 `w-4 h-4 mr-1`을 사용한다.
- 이전에 전체화면 버튼 높이에 맞추기 위해 사용한 `!h-7`, `!px-2`, `!text-xs` 재정의는 제거한다. 최신 요구사항인 공정추가 버튼과 동일 규격을 우선한다.
- 버튼 위치와 순서는 기존대로 DataGrid 왼쪽 툴바의 `설비배치 버튼 → 배치된 설비 타이틀/카운트`를 유지한다.

## 구현 범위

- 수정: `apps/frontend/src/app/(authenticated)/master/process/page.tsx`
- 수정: `apps/frontend/src/app/(authenticated)/master/process/components/ProcessEquipGrid.tsx`
- 테스트: 공정관리 구조 테스트에서 `14fr:11fr` 비율과 공정추가/설비배치 버튼 규격 일치를 검증한다.
- API, DB, 공용 DataGrid, 번역 키는 변경하지 않는다.

## 검증

1. 요구사항을 나타내는 구조 테스트를 먼저 추가·수정해 기존 구현에서 실패하는지 확인한다.
2. 최소 JSX/Tailwind 변경 후 공정관리 구조 테스트를 통과시킨다.
3. 프론트엔드 전체 테스트와 typecheck를 실행한다.
4. 사용자 기동 개발 서버와 인증 브라우저가 있으면 실제 화면에서 상단 축소, 하단 확대, 두 추가 버튼의 동일 크기를 확인한다.
