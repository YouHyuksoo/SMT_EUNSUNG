# 공정관리 배치 설비 툴바 배치 설계

## 목적

공정관리 하단의 배치 설비 영역에서 주요 동작과 현재 선택 정보를 DataGrid 도구 모음에 모아, 사용자가 설비 목록과 관련된 기능을 한 위치에서 찾게 한다.

## 현재 상태

`ProcessEquipGrid`는 카드 상단의 별도 헤더에 배치된 설비 타이틀과 카운트를 왼쪽에, 설비 배치 버튼을 오른쪽에 표시한다. DataGrid는 그 아래에서 내보내기와 전체화면 도구 모음을 별도로 렌더링한다.

## 변경 설계

- 카드 상단의 별도 헤더를 제거한다.
- DataGrid의 기존 `toolbarLeft` 슬롯을 사용한다.
- 도구 모음 왼쪽의 표시 순서는 다음과 같다.
  1. `설비 배치` 버튼
  2. `배치된 설비 - {공정코드} ({공정명}) · {건수}건` 타이틀
- 내보내기와 전체화면 버튼은 DataGrid의 기존 오른쪽 도구 영역에 그대로 둔다.
- 좁은 너비에서는 DataGrid의 기존 `flex-wrap` 동작을 따르며, 공용 DataGrid 구현은 변경하지 않는다.
- 공정 미선택 상태, 설비 배치 모달, 설비 제거, 라인 변경 동작은 변경하지 않는다.

## 구현 범위

- 수정: `apps/frontend/src/app/(authenticated)/master/process/components/ProcessEquipGrid.tsx`
- 테스트: 공정관리 구조 테스트에 `toolbarLeft` 내부의 버튼→타이틀 순서와 기존 별도 헤더 제거를 검증한다.
- 공용 컴포넌트, API, DB, 번역 키는 변경하지 않는다.

## 검증

1. 구조 테스트를 먼저 실패시키고 최소 구현으로 통과시킨다.
2. 프론트엔드 대상 테스트와 typecheck를 실행한다.
3. 개발 서버가 실행 중이고 브라우저 연결이 가능하면 공정관리 하단 툴바에서 버튼·타이틀·전체화면 버튼의 동일 높이 배치를 확인한다.
