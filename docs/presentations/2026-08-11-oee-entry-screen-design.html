01 요구사항 및 기능

목적

인증된 MES 사용자가 현장 작업자와 작업 대상을 선택하고, 서버가 확정한 업무일·근무구간 기준으로 비가동 이벤트를 기록한다.

생산수량·LOT·계획시간 입력은 이 화면 범위가 아니다.

사용자와 권한

로그인 사용자: API 실행자 및 감사정보

현장 작업자: ISYS_USERS.USER_ID로 별도 확인

테넌트: 인증 Guard의 조직·회사·사업장 범위

핵심 결과

RUNNING 열린 이벤트 없음

DOWNTIME 열린 이벤트 1건

현재 업무일의 시작·종료 이력을 시간순으로 표시한다.

03 비즈니스 규칙
구분규칙화면/서버 처리
리소스 계약SMT는 LINE, ASSY는 CELL만 허용하며 ASSY 상위 라인은 PROD2로 고정한다.목록과 저장 시 서버에서 다시 검증한다. ASSY CELL 미등록 시 LINE으로 대체하지 않는다.
업무일·구간KST 08:30을 업무일 경계로 사용하고, 실제 ICOM_WORKTIME_RANGES의 A~J 구간을 적용한다.클라이언트가 날짜·근무구간·시작/종료 시각을 전송하지 않는다.
비가동 사유MACHINE STATUS CODE 중 정상 N과 wildcard *를 제외한다.사유는 필수, 메모는 선택이며 최대 500자다.
상태 무결성동일 조직·리소스에는 열린 이벤트를 최대 1건만 허용한다.상태 미확인, 오류, 오프라인이면 시작·종료를 차단한다.
중복 요청시작·종료마다 64자 이하 request ID를 사용한다.네트워크 재시도는 같은 ID를 유지한다. 같은 endpoint에서 동일 ID의 payload가 달라지면 409로 거부한다.
오류 복구409 또는 저장 후 재조회 실패 시 서버 상태를 다시 조회한다.응답 확인 전 성공 상태로 전환하지 않으며 toast와 재시도 버튼을 제공한다.

06 완료 기준

기능

  • 작업자 확인 전 다음 단계 차단
  • SMT 12 LINE, ASSY 승인 CELL 표시
  • 시작·종료·정확 replay 성공

안전성

  • 오류·offline 상태전이 차단
  • 409 시 최신 상태 재조회
  • 시간·업무일은 서버 권위

사용성

  • 10인치 가로와 desktop 반응형
  • 64/72px 터치 목표
  • 실기기 회전·키보드·터치 검증
