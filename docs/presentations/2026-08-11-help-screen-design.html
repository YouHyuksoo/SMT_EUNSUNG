01요구사항 및 기능

목적

전체 화면의 사용법과 운영 가이드를 좌측 목차에서 찾고 우측 Markdown 본문으로 읽는다. 사용자와 운영자 문서를 같은 메뉴 코드로 분리한다.

정보 구조

좌측 4/12 목차: 사용자/운영자 탭, 제목/메뉴 코드 검색, manifest category/item. 우측 8/12: 선택 전 안내, 로딩, 미준비 문구 또는 Markdown.

현재 콘텐츠 기준

현재 상태manifest.json에는 기준정보와 SYS_CONFIG만 등록되어 있으며, SYS_CONFIG 한국어 문서는 “도움말 작성 예정” placeholder다.

03비즈니스·구현 규칙
구분규칙/현재 사실화면 처리
탭HelpTab = user | operator, 기본값은 user다.탭 버튼 active underline; 선택 menuCode는 탭 변경 후에도 state에 남을 수 있다.
목차 검색filterManifest가 category title, item title, menuCode를 trim/lowercase 부분일치한다.매칭 item이 없는 category는 제거하고, category title 자체가 매칭되면 남긴다.
문서 경로/help/{tab}/{lang}/{menuCode}.md; i18n.language.split('-')[0]로 언어를 얻는다.현재 언어가 없으면 ko를 fallback한다. raw text가 <로 시작하면 문서로 취급하지 않는다.
오류 은닉manifest fetch 실패는 manifest=null로 삼키고, 문서 fetch 실패는 notFound=true로 처리한다.manifest 오류용 별도 문구는 없고, 목차는 비어 보인다. 문서 오류는 “준비 중” 문구로 보인다.
MarkdownGFM, raw HTML, heading slug를 MarkdownRenderer가 지원한다.표·코드·이미지·링크·blockquote 스타일을 공통 help-md로 렌더한다.

03검증·수락·불일치
영역현재 확인수락 기준
목차manifest에는 17개 기준정보와 SYS_CONFIG만 실제 등록되어 있다.파일이 없는 메뉴를 임의로 목차에 노출하지 않고, 등록 item 선택이 정상 동작한다.
placeholderSYS_CONFIG ko 문서는 사용자/운영자 모두 작성 예정 문구다.이 문서가 실사용 가이드라고 표시하지 않는다. 콘텐츠 보강은 별도 문서 작업으로 분리한다.
fallback비-ko 문서가 없을 때 ko를 한 번 더 요청한다.ko가 있으면 fallback 표시, 둘 다 없으면 notFound 문구를 표시한다.
오류 은닉manifest 오류는 빈 목록, doc 오류는 notFound로 변환되어 원문이 화면에 나오지 않는다.현재 문구/상태를 보존하고, 오류 가시화 개선은 별도 결정이다.
렌더 안전fetchDoc는 HTML처럼 보이는 응답을 문서로 렌더하지 않는다.Markdown 표·코드·heading id·이미지 대체를 렌더하고 HTML 응답은 거부한다.
