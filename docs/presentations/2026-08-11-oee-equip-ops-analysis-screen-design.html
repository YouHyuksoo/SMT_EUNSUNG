03계산식·검증·Acceptance·Mismatches
지표페이지 주석의 참고식현재 구현·검증
계획달성율resultQty / planQty × 100achieveRate를 seed로 입력·표시. plan 0 보호 계산 없음.
가동율totalWorkSec / (standardWorkSec − equipmentDownSec)standardWorkSec 필드가 없어 런타임 계산 불가. availability seed 사용.
성능율(standardCT × resultQty) / totalWorkSecrow에 CT가 없고 nested T/T만 있어 performance seed 사용.
양품율goodQty / resultQtyOpsAgg에 goodQty가 없고 defectQty만 있어 quality seed 사용.
OEEavailability × performance × quality세 값과 oee의 seed 정합성만 검토 대상. 표시 단위는 이미 %.

Prototype Acceptance

  • 초기 6행과 첫 선택 행이 보인다.
  • 설비코드/명 검색이 양쪽 필드에 적용된다.
  • From/To 양 끝 날짜가 포함된다.
  • 행 선택 시 작업지시·비가동 상세가 함께 바뀐다.
  • OEE threshold 색상과 숫자 포맷이 보인다.
  • 빈 결과 메시지가 표시된다.

비수락

  • API 200/409, DB 행 순서, 실제 합계
  • 저장·수정·삭제·동시성
  • 재조회·캐시·실시간 값
  • 조직/권한 격리

Mismatches

  • “조회일자”는 seed filter이지 서버 조회가 아님.
  • 작업지시/비가동 하위 grid는 읽기용 mock.
  • 공식 OEE spec은 독립 OEE tables를 원천으로 하나 이 화면은 사용하지 않음.
  • 실제 품질 계산에 필요한 goodQty가 누락됨.
