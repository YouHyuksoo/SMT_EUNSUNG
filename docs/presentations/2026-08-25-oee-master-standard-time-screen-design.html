관리 목적

모델 기준 네 가지 표준시간을 초 단위로 저장하고 적용 시작일별 row를 조회한다. 모델코드는 자유 입력이 아니라 품목/모델 공용 picker에서 단일 선택한다.

STCTNTTT

현재 UI 구성

DataGrid pageSize 50, 통합검색, 새로고침, export/fullscreen, 우측 540px drawer, 2xl 모델 검색 modal(pageSize 15)로 구성된다. 행 관리에는 편집만 노출되고 삭제 버튼은 현재 없다.

OEE 계약 영향

표준시간의 CT_VALUE와 OEE 집계의 OEE_RESOURCE.IDEAL_CT는 현재 자동 연결되지 않는다. 이 화면의 CT 수정이 drilldown 성능율을 즉시 바꾼다고 표현하지 않는다.

Acceptance

  • DataGrid의 실제 필드와 540px drawer, 모델 modal 경로가 일치한다.
  • 원본 key 변경 PUT이 transaction으로 완료되고 중복은 409가 된다.

  • ST master CT 변경이 OEE_RESOURCE IDEAL_CT에 자동 반영되지 않는 현재 경계를 표시한다.
  • 인증·조직·감사자 계약 없이는 production 완료로 판정하지 않는다.
