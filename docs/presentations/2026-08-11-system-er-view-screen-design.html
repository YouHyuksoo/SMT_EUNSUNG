01요구사항 및 기능

목적·사용자

DBA/개발자가 테이블·컬럼·키 관계를 시각적으로 탐색하고, 추정 관계를 물리 FK로 승격하기 전 데이터를 검사한다. 일반 업무 CRUD 화면이 아니다.

탐색

좌측 table/module 검색과 다중 선택, 중앙 1-hop ReactFlow, 우측 관계 상세·risk·orphan 결과·preview SQL을 제공한다.

거버넌스 안전장치

보존 필수raw SQL 직접 입력 금지, 식별자 정규화, 부모 PK/UK·tenant·orphan 조건 확인, ENABLE VALIDATE preview와 “실행” 확인 문구를 유지한다.

03비즈니스·안전 규칙
구분규칙/현재 사실화면 처리
관계 표현PHYSICAL_FK는 solid blue, INFERRED는 dashed amber animated edge. 물리 FK는 이미 존재하는 관계로 신규 add 금지.edge click으로 우측 detail; inferred edge shape select 가능.
Risk부모 PK/UK 없음 또는 orphan 존재면 BLOCKED. tenant columns는 COMPANY,PLANT_CD pair를 본다. confidence/log-like/non-tenant가 score에 반영된다.LOW/MEDIUM/HIGH/BLOCKED badge와 reasons/recommendation 표시.
ADD FK/UKtable/column 존재, 동일 key/FK 중복, 부모 key, duplicate/null/orphan을 preview에서 재검사한다.조건 통과 후에만 structured SQL preview, ENABLE VALIDATE 실행.
위험 actionDROP_FK는 HIGH, DELETE_ORPHANS는 prod HIGH/dev MEDIUM. raw SQL payload는 받지 않는다.preview SQL 전체와 expected affected rows를 보여주고 정확한 실행 입력 없이는 button disabled.
실행 후dev에서는 migration SQL 파일·ERD 재생성·JSONL action log, 실패 시 compensation 시도를 한다.성공/ERD warning toast 후 graph refresh.

03DB·검증·수락 기준
영역현재 확인수락 기준
스키마 원천USER_TABLES, USER_TAB_COLUMNS, USER_TAB_COMMENTS, USER_CONSTRAINTS, USER_CONS_COLUMNS를 snapshot으로 읽고 10분 cache한다.summary/table/graph의 node/edge가 실제 snapshot 구조와 일치하고 action은 force reload한다.
식별자table/column은 ^[A-Z][A-Z0-9_]{0,127}$, constraint는 30자 이내 regex로 normalize한다.공백/SQL keyword/따옴표 입력이 action SQL에 삽입되지 않고 400으로 거부된다.
FK/UK safetyADD_FK는 parent key + orphan 0 + 기존 FK 없음; ADD_UK는 duplicate/null 0; SQL은 ENABLE VALIDATE.각 조건 실패 시 DB mutation 없이 BadRequest; preview.rawSqlAccepted=false.
DML safetyDELETE_ORPHANS preview expectedAffectedRows를 scan count로 계산, execute는 transaction과 after scan.prod risk HIGH 표시, 확인 문구 없이는 실행 불가, action log 기록.
실패/보상DDL action은 생성 constraint 보상 DROP을 시도하고 PARTIAL_FAILED/FAILED를 기록; dev migration/ERD 재생성.실패 후 cache invalidation/audit와 실제 constraint 상태를 확인한다.
인증 mismatcher-view.controller.ts에는 명시 @UseGuards(JwtAuthGuard) 또는 organization scope가 보이지 않는다.운영 노출 전 인증/권한/DB 사용자 경계를 별도 승인한다. 현재 UI 안전장치를 인증 보장으로 간주하지 않는다.
