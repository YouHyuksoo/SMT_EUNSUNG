01요구사항·현재 UI 와이어프레임

업무 목적

공정별 종합 화면에서 선택한 process/date를 전달받아 리소스별 OEE 순위를 시각화한다. 막대 hover는 OEE·가동·성능·양품·UPH·계획달성·가동/비가동 분을 보여준다.

현재 UI

상단에 종합 링크, 공정 select, 날짜 input(max today), 실시간/마감 스냅샷 badge가 있다. 데이터가 있으면 vertical Recharts BarChart와 각 row의 계산 기초값 검증 table을 렌더링한다.

resource 계약

backend는 집계 row를 OEE_RESOURCE.RESOURCE_ID로 묶고 IP_PRODUCT_LINE에서 resource code/name을 표시한다. 현재 master의 runtime process/type은 SMT/ASSY·LINE/CELL이다.

Acceptance

  • 오늘은 V_OEE_LIVE, 과거는 summary만 조회하고 미마감 409를 표시한다.
  • 차트 resource identity가 OEE_RESOURCE/LINE join과 일치한다.
  • 가동·성능·양품·OEE 재계산과 stored value가 한 row/shift에 보인다.
  • 누락 operand·0 이하 분모·empty·HTTP error가 서로 다른 상태다.
  • standard-time CT와 resource IDEAL_CT의 분리 및 work-result 미연결을 문서/검증에 남긴다.
