01요구사항과 사용자

목적

확인설비 코드·명·유형·라인·모델·제조사·통신·상태·사용·사진을 관리한다. BOM 패널에서는 PART/CONSUMABLE 품목과 재고·안전재고를 관리한다.

기준 테이블은 IMCN_MACHINE, BOM 품목은 EQUIP_BOM_ITEMS 모델이다.

사용자·권한

추정설비/보전 또는 생산기술 마스터 관리자. 실제 역할명은 UI에 없고 설비/BOM controller는 조직 ID decorator를 사용한다.

핵심 결과

검색·설비유형·라인·통신 필터, 이미지 썸네일, 상태/사용 배지.

04수락 기준
  • 조직별 설비 목록·필터·상태/사용 표시가 실제 API 행과 맞는다.
  • 설비 code immutable, conditional communication과 payload 저장 필드가 명확하다.
  • 사진 MIME/5MB·업로드 URL·삭제 DB/파일 결과를 함께 검증한다.
  • BOM module route가 200인지 확인하고 404면 UI를 완료 처리하지 않는다.
  • stockQty ≤ safetyStock red 표현과 숫자 저장을 확인한다.
  • 설비 edit와 BOM panel 동시 노출 금지, 409/404에서 컨텍스트 보존.

명시해야 할 mismatch

구현 불일치master-equip.module.ts에는 EquipMasterController만 등록되어 EquipBomController/Service/Repository가 앱 모듈에서 활성화되지 않는다.

구현 불일치entity의 commType/commConfig는 실제 컬럼이 없고 mqttTopic/serialPort/baudRate는 save body에서 제외된다.

구현 불일치EquipBomService/controller DTO가 organizationId와 company/plant 인자를 혼용하는 흔적이 있다. DB/API tenant 계약을 임의로 고치지 않는다.
