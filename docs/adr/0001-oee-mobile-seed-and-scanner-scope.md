# 0001. OEE MOBILE CELL Seed와 스캔 범위

- 결정일: 2026-08-10
- 상태: 승인
- 대상: `/oee/entry`, 생산2팀 CELL 기준정보

## 배경

OEE MOBILE 첫 배포에는 생산2팀 CELL 최초 등록용 SQL과 LINE/CELL 직접 선택 UI가 포함된다. 기존 계획과 선행계약에는 설비·CELL 스캔 후보도 기록되어 있으나, 실제 설비 코드와 LINE/CELL 매핑 및 Android 스캐너 검증은 완료되지 않았다.

CELL 관리 화면은 CELL 명칭, 사용 여부, 표시 순서를 운영자가 수정하도록 제공한다. 기존 seed가 재실행 때 이 값을 다시 초기값으로 덮어쓰면 운영 기준정보가 손실된다.

## 결정

1. `08_seed_production2_cells.sql`은 최초 insert만 수행한다.
2. 이미 존재하는 CELL의 명칭, 사용 여부, 표시 순서는 변경하지 않는다.
3. 동일한 실제 `PLANTS` 복합키를 다른 tenant가 소유하면 seed는 오류로 중단한다.
4. `/oee/entry` 첫 배포는 작업자가 LINE/CELL을 화면에서 직접 선택한다.
5. `/oee/mobile/resources/resolve`와 설비·CELL 스캔 UI는 후속 개발로 분리한다.
6. 후속 스캔 개발은 설비 코드 매핑, 미등록·중복 코드 처리, 실제 Android 스캐너 검증을 완료 기준에 포함한다.

## 결과

- seed 재실행은 운영자가 수정한 CELL 기준정보를 보존한다.
- 첫 배포는 검증된 비가동 시작·종료 흐름에 집중한다.
- 과거 계획·설계 문서의 스캔 항목은 당시 의도 기록으로 유지하며, 현재 범위 판단은 이 ADR이 우선한다.
