# SMT 설비(ES-) 라인코드 보정 기록 — 2026-10-27

## 무엇을 했나

- 대상: ESDBext `IMCN_MACHINE`, `MACHINE_CODE LIKE 'ES-%'`, ORGANIZATION_ID=1
- 기준: 생산1팀 `설비마스터_업로드양식(생산1팀 작성 完).xlsx`. G열 라인은 각 라인 첫 행에만 적혀 있어, 다음 라인 표시가 나올 때까지 같은 라인으로 읽었다.
- 바꾼 칸: `LINE_CODE` 만(46행). 설비명·공정·모델은 엑셀과 이미 같았다.
- ES-E-033(KTL-700F, KH-600597)은 엑셀에 라인이 없어 `*` 그대로 뒀다.
- IMCN_MACHINE 트리거 없음, 진행중 비가동(END_TIME IS NULL) 0건을 확인한 뒤 적용했다.

## 전후

| 라인 | 전(화면) | 후 = 엑셀 |
|---|---|---|
| 전체 | 45 | 85 |
| A~L | 라인별 누락·오배정 | A6 B6 C8 D8 E7 F7 G8 H8 I7 J6 K6 L8 |

확인: Oracle 집계 → 백엔드 API `/oee/work-result/downtime-board?processCode=SMT` → 프론트 프록시 → `/oee/multi-entry` 라인 탭 숫자가 모두 일치.
