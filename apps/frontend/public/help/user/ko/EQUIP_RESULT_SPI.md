# SPI 검사결과조회
## 화면 목적
기간·라인·PID·모델명·작업지시로 SPI 검사 이력을 확인합니다.
## 화면 구성
조회조건과 결과 그리드가 있습니다.
## ① 결과 컬럼
검사일시, 라인, 설비, 작업지시, PID, 모델명, 결과, 불량코드, 고객 모델명, 파일명, 등록일시, 등록자를 표시합니다.
## ② 조회 항목
기간은 필수이며 라인·PID·모델명·작업지시는 선택입니다.
## 버튼별 기능
| 버튼 | 동작 | 주의 |
|---|---|---|
| 조회 | 조건에 맞는 SPI 결과 조회 | 최대 5,000건 |
| 새로고침 | 같은 조건으로 재조회 | 조건 유지 |
| 내보내기 | 현재 그리드 저장 | 조회 결과 기준 |
## 업무 흐름
조건 선택 → 조회 → 판정과 불량코드 확인 → 필요 시 내보내기 순서로 사용합니다.
## 입력 규칙 / 검증
시작일은 종료일보다 늦을 수 없습니다.
## 자주 묻는 질문
원하는 PID가 없으면 라인과 작업지시 조건을 해제해 확인합니다.
## 관련 화면
SP 작업결과조회, AOI 검사결과조회
