# 성능 검사결과조회
## 화면 목적
EOL 성능검사의 채널별 전류·통전 결과를 추적합니다.
## 화면 구성
기간·라인·PID·모델명·작업지시 조건과 결과 그리드가 있습니다.
## ① 결과 컬럼
검사 시작·종료, 라인, 설비, 작업지시, PID, 모델명, 결과, 불량코드, 채널, 전류값·전류결과 1~4, 통전값·통전결과 1~4, 파일명, 등록일시, 등록자를 표시합니다.
## 버튼별 기능
조회·새로고침·내보내기를 지원합니다.
## 업무 흐름
식별조건 입력 → 조회 → 전체 결과 확인 → 채널별 전류·통전 결과 확인 순서입니다.
## 입력 규칙 / 검증
기간 역전은 허용되지 않습니다.
## 자주 묻는 질문
“성능 검사”의 원천은 레거시 EOL 결과 테이블입니다.
## 관련 화면
ICT 검사결과조회, ROM WRITE 작업결과조회
