# REFLOW 작업결과조회
## 화면 목적
Reflow 측정 시점의 벨트 속도, 산소농도, 존별 온도를 확인합니다.
## 화면 구성
기간·라인·Job File 조건과 결과 그리드가 있습니다.
## ① 결과 컬럼
측정일시, 라인, 설비, Job File, Belt Speed, 산소농도, Top 1~13, Bottom 1~13, 파일명, 등록일시, 등록자를 표시합니다.
## 버튼별 기능
조회·새로고침·내보내기를 지원합니다.
## 업무 흐름
기간과 라인 선택 → 필요 시 Job File 입력 → 조회 → 존별 온도 편차 확인 순서입니다.
## 입력 규칙 / 검증
기간 역전은 허용되지 않습니다.
## 자주 묻는 질문
열이 많으므로 그리드 가로 스크롤과 열 필터를 사용합니다.
## 관련 화면
설비마스터
