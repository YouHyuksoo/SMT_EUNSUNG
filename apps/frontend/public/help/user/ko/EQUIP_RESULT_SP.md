# SP 작업결과조회
## 화면 목적
기간·라인·PID·모델명·작업지시로 SP 작업 이력을 확인합니다.
## 화면 구성
상단 조회조건과 하단 결과 그리드로 구성됩니다.
## ① 결과 컬럼
검사일시, 라인, 설비, 작업지시, PID, 모델명, 결과, 불량코드, Job File, Stencil ID, Paste ID, Squeegee ID, 생산수, 파일명, 등록일시, 등록자를 표시합니다.
## ② 조회 항목
기간은 필수이며 라인·PID·모델명·작업지시는 선택 조건입니다.
## 버튼별 기능
| 버튼 | 언제 사용 | 동작 | 결과 / 주의 |
|---|---|---|---|
| 조회 | 조건 입력 후 | 결과를 최대 5,000건 조회 | 기간을 좁히면 빠릅니다. |
| 새로고침 | 같은 조건 재조회 | 최신 결과를 다시 조회 | 입력 조건은 유지됩니다. |
| 내보내기 | 결과 확인 후 | 그리드 데이터를 파일로 저장 | 현재 조회 결과 기준입니다. |
## 업무 흐름
1. 기간과 필요 조건을 선택합니다. 2. **조회**를 누릅니다. 3. 결과·불량코드와 인쇄 조건을 확인합니다.
## 입력 규칙 / 검증
시작일은 종료일보다 늦을 수 없습니다.
## 자주 묻는 질문
결과가 없으면 기간, 라인, PID의 일부 입력값을 줄여 다시 조회합니다.
