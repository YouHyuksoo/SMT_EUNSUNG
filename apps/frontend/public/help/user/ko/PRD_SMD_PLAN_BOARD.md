# 반제품생산계획 현황판

## 화면 목적

생산 1팀이 엑셀로 쓰던 일일 생산계획 표를 화면으로 옮겼습니다. 날짜를 고르면 그날 반제품생산계획을 라인별 블록으로 보여 주고, 시간대별 센서 실적을 주간·야간으로 나눠 보여 줍니다. 날짜 전체 공지와 라인별 특이사항을 적어 둘 수 있습니다.

## 화면 구성

- 상단: 조회일(기본 오늘), 오늘 버튼, 새로고침
- 공지 영역: "YYYY년 MM월 DD일 생산 1팀 생산계획" 제목과 그날 공지 줄, 공지 편집 버튼
- 라인 블록: 생산 1팀(SMT) 라인마다 하나씩, 넓은 화면에서는 두 줄로 배치합니다. 그날 계획이 없는 라인도 특이사항을 적을 수 있게 빈 블록으로 나옵니다.

## ① 라인 블록 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| 라인 글자 | 블록 왼쪽의 큰 글자. 라인명에서 "라인"을 뺀 글자(A, B …)입니다. |
| MODEL | 계획 모델명. 옆의 T/B 는 PCB 면입니다. "계획 외" 표시는 아래 설명을 보세요. |
| 품번 | 계획의 품목코드 |
| LOT / OP / AOI / 수삽/외관 / UPH(2H) | 연결할 데이터가 없어 비워 둡니다. |
| LOT 수량 | 계획수량. 롯트카드 LOT 수량과 같은 값입니다. |
| 생산계획 | 반제품생산계획 화면에서 입력한 시간대 계획 10칸의 합입니다. 시간대 계획을 넣지 않았으면 0 입니다. |
| 근무 | 주간(08:30~20:30) / 야간(20:30~다음날 08:30). 계획 한 건이 두 줄로 나옵니다. |
| A~E TIME | 시간대별 센서 실적 수량. 주간 줄은 A~E, 야간 줄은 F~J 구간입니다(머리글 아래 "야간 F" 등). 시간대 계획을 넣은 칸은 숫자 아래 "계획 n" 이 붙습니다. |
| 합계 | 그 줄(근무조)의 실적 합 |
| 특이사항 줄 | 블록 아래쪽 왼쪽에 세로선이 있는 줄. 라인별로 적은 메모입니다. |
| 합계(맨 아래) | 블록 안 모든 행의 주간·야간 시간대별 실적 합 |

시간대 구간(머리글에 마우스를 올리면 보임): A 08:30~10:30, B 10:30~12:40, C 12:40~15:30, D 15:30~17:40, E 17:40~20:30, F 20:30~22:30, G 22:30~00:30, H 00:30~03:30, I 03:30~05:30, J 05:30~08:30.

**계획 외**: 그날 센서 실적 중 같은 날 계획과 라인·모델·서픽스·PCB 면이 맞지 않는 실적입니다. 전날 이전 계획을 이어서 생산하면 여기에 나옵니다. LOT 수량·생산계획 칸은 비어 있습니다.

## 버튼별 기능

| 버튼 | 언제 사용 | 동작 | 결과 / 주의 |
|------|------|------|------|
| 오늘 | 오늘 날짜로 돌아갈 때 | 조회일을 오늘로 바꾸고 다시 조회 | 날짜를 바꾸면 바로 조회됩니다. |
| 새로고침 | 실적을 다시 볼 때 | 같은 날짜를 다시 조회 | 센서 실적은 계속 쌓이므로 필요할 때 누릅니다. |
| 공지 편집 | 날짜 전체 공지를 적을 때 | 편집칸을 엽니다 | 한 줄이 공지 한 항목입니다. |
| 특이사항 | 라인 메모를 적을 때 | 그 라인 블록 아래에 편집칸을 엽니다 | 한 줄이 메모 한 줄입니다. |
| 저장 | 편집을 마쳤을 때 | 그 날짜·라인의 메모를 입력한 내용으로 바꿉니다 | 빈 줄은 저장하지 않습니다. 전부 지우고 저장하면 확인창이 뜹니다. |
| 취소 | 편집을 그만둘 때 | 편집칸을 닫습니다 | 입력한 내용은 저장되지 않습니다. |

## 업무 흐름

1. 조회일을 고릅니다(기본 오늘).
2. 라인 블록에서 계획 모델과 주간·야간 시간대 실적을 확인합니다.
3. 그날 전체 공지는 **공지 편집**, 라인별 메모는 블록 왼쪽 **특이사항**으로 적고 **저장**합니다.
4. 메모를 고치거나 지울 때도 같은 편집칸에서 줄을 고치거나 지운 뒤 저장합니다.

## 입력 규칙 / 검증

- 메모는 날짜 + 라인 단위로 저장됩니다. 다른 날짜에는 보이지 않습니다.
- 한 블록(또는 공지)에 30줄까지, 한 줄은 500자까지 저장됩니다.
- 저장하면 그 날짜·라인의 메모 전체를 입력한 내용으로 바꿉니다. 두 사람이 같은 블록을 동시에 고치면 나중에 저장한 내용이 남습니다.
- 계획 자체(모델·수량·시간대 계획)는 이 화면에서 고칠 수 없습니다. 반제품생산계획 화면에서 고칩니다.

## 자주 묻는 질문

**Q. 시간대 칸이 비어 있거나 0 입니다.**
A. 그 시간대에 센서 실적이 없거나, 같은 날 계획과 모델·PCB 면이 달라 "계획 외" 행으로 따로 나왔을 수 있습니다.

**Q. 야간 실적은 어느 날짜에 나오나요?**
A. 08:30 에 업무일이 바뀝니다. 10월 2일 20:30 ~ 10월 3일 08:30 실적은 10월 2일 야간 줄에 나옵니다.
