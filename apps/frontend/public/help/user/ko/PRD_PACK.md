# 제품포장관리(PID)

완성된 기판(PID)을 박스에 담고 포장완료하는 화면입니다.

## 포장

1. 라인·공정과 모델을 고르고 박스를 만듭니다.
2. 박스를 고른 뒤 담을 기판의 PID 를 하나씩 찍습니다. 잘못 담았으면 **빼기**로 바꿔 다시 찍습니다.
3. 다 담으면 **포장완료**를 누릅니다.

## 박스라벨 출력

- **BarTender 출력**을 켜 두면 포장완료 때 **출력 매수**만큼, **재출력** 때 1장을 찍습니다.
- 라벨 양식과 값은 **제품별 라벨양식 관리**에 등록된 그 모델의 박스 양식을 씁니다. 양식이 없으면 출력하지 않고 알려 줍니다.
- 이 PC 에 **BarTender** 와 **EUNSUNG Print Agent** 가 있어야 합니다. Print Agent 는 화면 위쪽 프린터 아이콘에서 내려받아 한 번 실행하면 됩니다.
- **프린터**를 비워 두면 양식에 저장된 프린터로 찍습니다. 다른 프린터로 찍으려면 목록에서 고릅니다. 이 설정은 PC 마다 따로 기억합니다.
- 출력이 실패해도 포장완료는 그대로입니다. 원인을 고친 뒤 **재출력**으로 다시 찍습니다.
