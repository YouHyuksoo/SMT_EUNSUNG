# ROM WRITE 작업결과조회
## 화면 목적
ROM 기록 작업의 프로그램·Check Sum·작업시간을 확인합니다.
## 화면 구성
기간·라인·PID·모델명·작업지시 조건과 결과 그리드가 있습니다.
## ① 결과 컬럼
검사일시, 라인, 설비, 작업지시, PID, 모델명, 결과, 불량코드, Pin 수, 프로그램, Check Sum, 작업시간, 파일명, 등록일시, 등록자를 표시합니다.
## 버튼별 기능
조회, 동일 조건 새로고침, 결과 내보내기를 지원합니다.
## 업무 흐름
식별조건 입력 → 조회 → 프로그램과 Check Sum 대조 → 결과 확인 순서입니다.
## 입력 규칙 / 검증
기간 역전은 허용되지 않습니다.
## 자주 묻는 질문
프로그램 일치 여부는 프로그램과 Check Sum을 함께 확인합니다.
