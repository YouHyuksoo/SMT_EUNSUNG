# ICT 검사결과조회
## 화면 목적
ICT 공정의 부품별 측정값과 판정 근거를 추적합니다.
## 화면 구성
기간·라인·PID·모델명·작업지시 조건과 결과 그리드로 구성됩니다.
## ① 결과 컬럼
검사일시, 라인, 설비, 작업지시, PID, 모델명, 결과, 불량코드, Step, 부품명, 실측값, 기준값, 상한, 하한, 파일명, 등록일시, 등록자를 표시합니다.
## 버튼별 기능
조회는 최대 5,000건을 가져오고, 새로고침은 같은 조건을 다시 실행하며, 내보내기는 현재 결과를 저장합니다.
## 업무 흐름
기간 설정 → PID 또는 작업지시 입력 → 조회 → 실측값과 상·하한 비교 순서로 확인합니다.
## 입력 규칙 / 검증
기간 역전은 허용되지 않습니다. 나머지 조건은 부분 일치입니다.
## 자주 묻는 질문
불량 상세는 결과와 불량코드, 해당 행의 실측값·상한·하한을 함께 확인합니다.
