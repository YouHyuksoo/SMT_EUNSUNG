# 매거진발행이력

## 화면 목적

매거진 라벨별 발행·공정 수불 내역을 이력, 집계, 매트릭스 형태로 조회하는 화면입니다.

## 화면 구성

- 조회 조건: 라인, 공정, 모델명, 매거진 라벨번호, RUN NO, 발행일 기간
- 조회 형태: 이력, 집계, 매트릭스
- 결과 표: 조건과 조회 형태에 맞는 수불 내역과 수량 합계

## ① 조회 결과 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| 라벨유형 | 매거진 라벨의 업무 유형 |
| RUN NO | 생산 실행 번호 |
| 매거진 라벨번호 | 발행된 매거진 라벨 식별번호 |
| 발행일시 | 라벨 이력 등록 일시 |
| 라인 / 공정 | 수불이 발생한 생산 라인과 공정 |
| 수불일시 | 공정 입출고가 기록된 일시 |
| 모델명 / 서픽스 | 생산 모델과 파생 구분 |
| 품목코드 / PCB 구분 | 대상 품목과 PCB 구분 |
| 수량 / 불량수량 | 수불 수량과 불량 수량 |
| 대체 매거진 라벨번호 | 이동·대체 처리된 연결 라벨번호 |

집계와 매트릭스에서는 상세 라벨번호 대신 일자·라벨유형별 합계가 표시됩니다.

## 버튼별 기능

| 버튼 | 언제 사용 | 동작 | 결과 / 주의 |
|------|------|------|------|
| 조회 | 조건 입력 후 | 현재 조회 형태로 검색 | 최대 5,000건을 표시합니다. |
| 새로고침 | 같은 조건으로 다시 확인할 때 | 현재 조건을 재조회 | 조건은 초기화되지 않습니다. |
| 이력 / 집계 / 매트릭스 | 결과 표현을 바꿀 때 | 조회 형태 선택 | 형태 선택 후 조회를 눌러 결과를 갱신합니다. |

## 업무 흐름

1. 발행일 기간과 필요한 라인·공정 조건을 지정합니다.
2. 필요하면 모델명, 매거진 라벨번호 또는 RUN NO를 입력합니다.
3. 이력·집계·매트릭스 중 조회 형태를 선택합니다.
4. **조회**를 눌러 결과와 수량 합계를 확인합니다.
5. 필요하면 표의 필터나 내보내기를 사용합니다.

## 입력 규칙 / 검증

- 텍스트 조건은 입력값으로 시작하는 데이터를 찾습니다.
- 발행일 종료일은 해당 날짜 전체를 포함합니다.
- 로그인한 조직의 데이터만 조회됩니다.

## 자주 묻는 질문

**조회 결과가 없어요.** 기간을 넓히고 라인·공정·라벨번호 조건을 하나씩 해제해 확인하세요.

**수량이 음수로 보여요.** 원본 이력에서 출고·취소 성격의 수불은 음수로 기록될 수 있습니다.

## 관련 화면

현재 직접 연결된 관련 화면은 없습니다.
