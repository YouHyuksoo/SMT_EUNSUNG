# AOI 검사결과조회
## 화면 목적
AOI 원판정과 작업자 리뷰 결과를 비교합니다.
## 화면 구성
기간, 라인, PID, 모델명, 작업지시, 검사결과, 리뷰결과 조건과 결과 그리드가 있습니다.
## ① 결과 컬럼
검사일시, 라인, 설비, 작업지시, PID, 모델명, 결과, 불량코드, 고객 모델명, 리뷰일시, 리뷰결과, Job File, 파일명, 등록일시, 등록자를 표시합니다.
## 버튼별 기능
조회·새로고침·내보내기를 지원합니다. 결과 선택값은 전체, OK, NG, USEROK, USERNG입니다.
## 업무 흐름
조건 입력 → 조회 → 원판정과 리뷰판정 비교 → 불량코드 확인 순서로 사용합니다.
## 입력 규칙 / 검증
기간은 역전할 수 없으며 선택하지 않은 판정 조건은 전체로 처리됩니다.
## 자주 묻는 질문
원판정과 리뷰판정이 다르면 리뷰일시와 리뷰결과를 기준으로 후속 분석합니다.
