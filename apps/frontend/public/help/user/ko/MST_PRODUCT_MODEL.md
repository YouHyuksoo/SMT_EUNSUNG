# 제품모델관리

제품 모델 목록과 모델별 **BOM 전개 방식**을 관리하는 화면입니다. BOM 전개 방식은 AOI 검사에서 양품이 나온 보드가 어떤 반제품이 되는지, 제품을 입고할 때 공정재고에서 무엇을 빼는지 정하는 기준입니다.

## 보는 방법

- 검색창에 모델명, 고객사품번, 규격, 고객사, 품목코드 일부를 넣으면 목록이 좁혀집니다.
- 머리글 옆 숫자는 (검색 결과 / 전체 · 미분류 수)입니다.

## BOM 전개 방식

| 전개 방식 | 뜻 | T면·B면 생산 품목 |
|---|---|---|
| 제품 직하 TOP·BOT | 제품 바로 아래에 TOP 반제품과 BOT 반제품이 있다 | T면 = TOP 반제품, B면 = BOT 반제품 |
| SUB-Assy 아래 TOP·BOT | 중간 반제품(SUB-Assy) 아래에 TOP·BOT이 있다 | 위와 같다 |
| TOP 안에 BOT | BOT 반제품이 TOP 반제품 안에 들어간다 | 위와 같다 |
| 단면 반제품 | SMT 반제품이 하나뿐이다 | 실적을 셀 면 하나만 채운다 |
| 원자재만 | 반제품 없이 원자재만 있다 | 실적을 셀 면에 제품 자신을 채운다 |
| 미분류 | 자동으로 정하지 못했다 | 사람이 정해야 한다 |

**SUB 공정 품목**은 SUB-Assy 아래 TOP·BOT 구조에서 TOP·BOT을 담는 SUB-Assy 품목입니다. 제품을 입고할 때 SUB-Assy에 직접 달린 원자재까지 소비하는 기준이 됩니다.

생산 품목이 채워진 면의 AOI 양품만 실적으로 셉니다. 원자재만이거나 단면 반제품인데 T·B 면을 따로 생산하면 각 면을 하나의 모델로 보고 두 면에 같은 품목을 넣습니다. 이때 실적은 면마다 세고, 공정재고는 두 면을 거쳐 1개가 되도록 면마다 절반씩 움직입니다.

## 자동 분류

**자동 분류**를 누르면 BOM 모양, 품목명(TOP·BOT), 최근 6개월 SMT 런카드의 면으로 전체 모델을 다시 분류합니다.

- **구분**이 '사람'인 모델은 건너뜁니다.
- 자동으로 정하지 못했거나 확인이 필요하면 **분류 메모**에 이유가 남습니다. 예: 최근 런카드가 없어 실적을 셀 면을 정해야 하는 경우.

## 직접 정하기

1. 목록에서 모델 행을 누릅니다.
2. **BOM 전개 방식**을 고릅니다.
3. **T면 생산 품목**, **B면 생산 품목**, 필요하면 **SUB 공정 품목**을 고릅니다. 후보는 제품 자신과 그 BOM의 반제품입니다. 대괄호 안의 T·B는 품목명·코드로 추정한 면입니다.
4. **저장**을 누릅니다. 구분이 '사람'으로 바뀌고, 이후 자동 분류가 덮어쓰지 않습니다.

품목코드가 없는 모델은 정할 수 없습니다.
