# 반제품생산실적관리

## 화면 목적

라인 센서가 올린 반제품 생산실적을 반제품생산계획과 맞춰 계획별 주간·야간 실적과 남은 잔량을 확인합니다. 센서 집계가 마운터 기준 실적과 다르면 근무조별 수기 실적을 넣어 잔량 계산을 고칩니다.

## 화면 구성

- 탭: 계획별 주야 실적, 실적 목록, 라인·모델 합계
- 조회 조건: 계획일(실적 목록·합계 탭은 집계일), 라인, 모델명, 공정(실적 목록·합계 탭만)
- 버튼: 조회, 수기실적(계획별 주야 실적 탭), 수정·삭제(실적 목록 탭)

## 근무조 기준

| 근무조 | 시간 | 센서 시간구분 |
|------|------|------|
| 주간 | 08:30 ~ 20:30 | A ~ E |
| 야간 | 20:30 ~ 다음날 08:30 | F ~ J |

- 야간은 계획일 저녁 20:30부터 다음날 아침 08:30까지입니다. 다음날 새벽 생산분도 계획일 실적으로 들어갑니다.
- 자동 실적은 조회 버튼을 누른 시점의 센서 실적입니다. 최신 값을 보려면 다시 조회합니다.

## ① 계획별 주야 실적 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| 계획일 / 순번 | 반제품생산계획의 계획일과 계획순번 |
| 라인 / 모델명 / PCB면 / 서픽스 | 계획한 라인과 모델. 자동 실적은 계획일·라인·모델·서픽스·PCB면이 같은 센서 실적을 더합니다 |
| 계획수량 | 반제품생산계획의 계획수량 |
| 주간실적(자동) | 계획일 08:30~20:30 센서 실적 합. 주간 수기 값이 있으면 줄을 그어 표시하고 계산에 쓰지 않습니다 |
| 주간실적(수기) | 사람이 넣은 주간 실적. 값이 있으면 자동 대신 이 값을 씁니다 |
| 야간실적(자동) | 계획일 20:30~다음날 08:30 센서 실적 합 |
| 야간실적(수기) | 사람이 넣은 야간 실적 |
| 주간 잔량 | 계획수량 − 주간 실적 |
| 야간 잔량 | 계획수량 − 주간 실적 − 야간 실적. 주간 실적까지 반영한 남은 양입니다 |
| 같은 모델 계획 | 같은 날·라인·모델·서픽스·PCB면 계획이 2건 이상이면 건수를 보여 줍니다. 이때 자동 실적이 계획마다 똑같이 붙으므로 수기로 나눠 넣습니다 |
| 최종 센서 집계 | 이 계획에 붙은 센서 실적이 마지막으로 올라온 시각 |
| 주간 수기 입력 / 야간 수기 입력 | 수기 실적을 마지막으로 넣은 사람과 시각 |
| 품목코드 / 작업지시번호 / 계획상태 / 확정 | 반제품생산계획 정보 |

- 잔량이 음수(빨간색)면 계획보다 더 생산한 것입니다.

## ② 실적 목록·라인·모델 합계

| 탭 | 내용 |
|------|------|
| 실적 목록 | 센서가 시간구분마다 쌓은 실적 행. 실적수량과 보정수량을 고치거나 행을 지울 수 있습니다. 센서 원시값은 고칠 수 없습니다 |
| 라인·모델 합계 | 실적 목록과 같은 조건을 라인·모델별로 합친 값 |

## 버튼별 기능

| 버튼 | 언제 사용 | 동작 | 결과 / 주의 |
|------|------|------|------|
| 조회 | 항상 | 선택한 탭을 조건으로 조회 | 계획별 주야 실적 탭은 조회 시점 기준으로 자동 실적을 다시 계산합니다 |
| 수기실적 | 계획별 주야 실적 탭에서 계획 행을 선택했을 때 | 주간·야간 수기 실적 입력창을 엽니다 | 칸을 비우고 저장하면 그 근무조는 자동 실적으로 돌아갑니다 |
| 수기 모두 지우기 | 수기실적 입력창에서, 수기 값이 있을 때 | 그 계획의 주간·야간 수기 실적을 모두 지웁니다 | 자동 실적으로 다시 계산합니다 |
| 수정 | 실적 목록 탭에서 행을 선택했을 때 | 센서 실적 행의 실적수량·보정수량을 고칩니다 | 센서 실적 자체가 바뀝니다. 계획별 수량만 고치려면 수기실적을 씁니다 |
| 삭제 | 실적 목록 탭에서 행을 선택했을 때 | 센서 실적 행을 지웁니다 | 되돌릴 수 없습니다 |

## 업무 흐름

1. 계획별 주야 실적 탭에서 계획일·라인을 정하고 조회합니다.
2. 자동 실적과 마운터 기준 실적을 비교합니다.
3. 다르면 계획 행을 선택하고 수기실적을 눌러 주간 또는 야간 수량을 넣고 저장합니다.
4. 잔량이 수기 값 기준으로 다시 계산됐는지 확인합니다.

## 자주 묻는 질문

- **Q.** 수기 실적을 넣으면 센서 실적도 바뀌나요?
  **A.** 바뀌지 않습니다. 수기 실적은 별도로 저장되고 계획별 실적·잔량 계산에만 쓰입니다.
- **Q.** 수기 실적을 잘못 넣었습니다.
  **A.** 수기실적 입력창에서 해당 칸을 비우고 저장하거나, 수기 모두 지우기를 누르면 자동 실적으로 돌아갑니다.
- **Q.** 계획은 있는데 자동 실적이 0입니다.
  **A.** 계획일·라인·모델·서픽스·PCB면이 같은 센서 실적이 없는 경우입니다. 계획일과 다른 날 생산했거나 다른 라인·모델로 생산했으면 자동으로 붙지 않으므로 수기로 넣습니다.
