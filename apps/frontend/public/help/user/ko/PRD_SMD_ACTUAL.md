# 반제품생산실적관리

## 화면 목적

생산실적(조립실적)을 반제품생산계획과 맞춰 계획별 주간·야간 실적과 남은 잔량을 확인합니다. 생산실적은 AOI 양품 판정이 들어올 때 자동으로 더해지고, 보정도 같은 실적에 쌓입니다. OEE 작업실적 화면은 SMT 실적을 받지 않습니다(2026-10-19부터). 계획별 수량만 다르면 근무조별 수기 실적을 넣어 잔량 계산을 고치고, 생산실적 자체가 틀렸으면 보정 행을 넣습니다.

## 화면 구성

- 탭: 계획별 주야 실적, 실적 목록, 라인·모델 합계
- 조회 조건: 계획일(실적 목록·합계 탭은 작업일), 라인, 모델명, 공정(실적 목록·합계 탭만)
- 버튼: 조회, 수기실적(계획별 주야 실적 탭), 보정 등록·수정·삭제(실적 목록 탭)

## 근무조 기준

| 근무조 | 시간 | 시간구분 |
|------|------|------|
| 주간 | 08:30 ~ 20:30 | A ~ E |
| 야간 | 20:30 ~ 다음날 08:30 | F ~ J |

- 야간은 계획일 저녁 20:30부터 다음날 아침 08:30까지입니다. 다음날 새벽 생산분도 계획일 실적으로 들어갑니다.
- 자동 실적은 조회 버튼을 누른 시점의 생산실적입니다. 최신 값을 보려면 다시 조회합니다.

## 생산실적이 생기는 경우

| 구분 | 언제 | 수량 |
|------|------|------|
| AOI 자동 | AOI 최종 판정(리뷰 결과가 있으면 리뷰 결과)이 양품일 때 바로 | PID 1개 = 1개. 배열 PCB 모델은 모델 마스터의 PCB 수량만큼 |
| 수기 | 2026-10-18까지 작업실적 화면에서 SMT 라인 실적을 완료했을 때 (지금은 생기지 않음) | 작업실적 수량. 취소는 같은 시각의 음수 행 |
| 보정 | 이 화면의 보정 등록·수정·삭제 | 입력한 차이만큼 |

- 생산 품목은 런카드의 제품·면(T/B)으로 제품 BOM에서 찾습니다(그 면이 표시된 반제품, 원자재만인 제품은 제품 자신). BOM에 그 면의 반제품 표시가 없으면 AOI 자동 실적이 생기지 않습니다(제품모델관리의 BOM 전개 방식에서 지정).
- 런카드 번호가 없는 AOI 검사 행은 실적에 넣지 않습니다.
- 생산실적이 생기면 공정재고도 같이 움직입니다(반제품 공정입고, 바로 아래 자품목 공정출고).

## ① 계획별 주야 실적 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| 계획일 / 순번 | 반제품생산계획의 계획일과 계획순번 |
| 라인 / 모델명 / PCB면 / 서픽스 | 계획한 라인과 모델. 자동 실적은 계획일·라인·모델·서픽스·PCB면이 같은 생산실적을 더합니다 |
| 계획수량 | 반제품생산계획의 계획수량 |
| 주간실적(자동) | 계획일 08:30~20:30 생산실적 합. 주간 수기 값이 있으면 줄을 그어 표시하고 계산에 쓰지 않습니다 |
| 주간실적(수기) | 사람이 넣은 주간 실적. 값이 있으면 자동 대신 이 값을 씁니다 |
| 야간실적(자동) | 계획일 20:30~다음날 08:30 생산실적 합 |
| 야간실적(수기) | 사람이 넣은 야간 실적 |
| 주간 잔량 | 계획수량 − 주간 실적 |
| 야간 잔량 | 계획수량 − 주간 실적 − 야간 실적. 주간 실적까지 반영한 남은 양입니다 |
| 같은 모델 계획 | 같은 날·라인·모델·서픽스·PCB면 계획이 2건 이상이면 건수를 보여 줍니다. 이때 자동 실적이 계획마다 똑같이 붙으므로 수기로 나눠 넣습니다 |
| 최종 실적 시각 | 이 계획에 붙은 생산실적의 마지막 실적 시각 |
| 주간 수기 입력 / 야간 수기 입력 | 수기 실적을 마지막으로 넣은 사람과 시각 |
| 품목코드 / 작업지시번호 / 계획상태 / 확정 | 반제품생산계획 정보 |

- 잔량이 음수(빨간색)면 계획보다 더 생산한 것입니다.

## ② 실적 목록·라인·모델 합계

| 탭 | 내용 |
|------|------|
| 실적 목록 | 생산실적 행. 작업일·실적시각·구분(AOI 자동/수기/보정)·런카드·생산품목·비고(사유)를 보여 줍니다 |
| 라인·모델 합계 | 실적 목록과 같은 조건을 라인·모델별로 합친 값 |

## 버튼별 기능

| 버튼 | 언제 사용 | 동작 | 결과 / 주의 |
|------|------|------|------|
| 조회 | 항상 | 선택한 탭을 조건으로 조회 | 계획별 주야 실적 탭은 조회 시점 기준으로 자동 실적을 다시 계산합니다 |
| 수기실적 | 계획별 주야 실적 탭에서 계획 행을 선택했을 때 | 주간·야간 수기 실적 입력창을 엽니다 | 칸을 비우고 저장하면 그 근무조는 자동 실적으로 돌아갑니다. 생산실적은 바뀌지 않습니다 |
| 수기 모두 지우기 | 수기실적 입력창에서, 수기 값이 있을 때 | 그 계획의 주간·야간 수기 실적을 모두 지웁니다 | 자동 실적으로 다시 계산합니다 |
| 보정 등록 | 실적 목록 탭 | 런카드·라인·실적 시각·수량(늘리면 +, 줄이면 −)·사유를 넣어 보정 행을 만듭니다 | 행을 선택하고 누르면 그 행의 런카드·라인·시각이 채워집니다. 작업일·시간대는 실적 시각으로 정해집니다 |
| 수정 | 실적 목록 탭에서 행을 선택했을 때 | 새 실적수량과 사유를 넣습니다 | 원래 행은 그대로 두고 (새 수량 − 지금 수량)만큼 보정 행을 더합니다 |
| 삭제 | 실적 목록 탭에서 행을 선택했을 때 | 사유를 넣습니다 | 원래 행은 그대로 두고 같은 수량의 음수 보정 행을 더해 0으로 만듭니다 |

## 업무 흐름

1. 계획별 주야 실적 탭에서 계획일·라인을 정하고 조회합니다.
2. 자동 실적과 마운터 기준 실적을 비교합니다.
3. 계획별 수량만 다르면 계획 행을 선택하고 수기실적을 눌러 주간 또는 야간 수량을 넣고 저장합니다.
4. 생산실적 자체가 틀렸으면 실적 목록 탭에서 보정 등록 또는 수정으로 보정 행을 넣습니다.

## 자주 묻는 질문

- **Q.** 수기 실적을 넣으면 생산실적도 바뀌나요?
  **A.** 바뀌지 않습니다. 수기 실적은 별도로 저장되고 계획별 실적·잔량 계산에만 쓰입니다. 생산실적을 고치려면 보정 등록·수정을 씁니다.
- **Q.** 실적 행을 수정했는데 원래 행 수량이 그대로입니다.
  **A.** 원래 행은 바꾸지 않고 차이만큼 '보정' 행을 더합니다. 합계와 계획별 실적에는 보정 행까지 더해진 값이 나옵니다.
- **Q.** 계획은 있는데 자동 실적이 0입니다.
  **A.** 계획일·라인·모델·서픽스·PCB면이 같은 생산실적이 없는 경우입니다. 계획일과 다른 날 생산했거나 다른 라인·모델로 생산했으면 자동으로 붙지 않습니다. 제품 BOM에 그 면의 생산 품목이 표시되지 않았거나 AOI 검사 행에 런카드 번호가 없어도 AOI 자동 실적이 생기지 않습니다.
