# ROUTER 작업결과조회
## 화면 목적
라우터 가공 결과와 주요 가공 조건을 추적합니다.
## 화면 구성
기간·라인·PID·모델명·작업지시 조회조건과 결과 그리드가 있습니다.
## ① 결과 컬럼
검사일시, 라인, 설비, 작업지시, PID, 모델명, 결과, 불량코드, RPM, Bit, 파일명, 등록일시, 등록자를 표시합니다.
## 버튼별 기능
조회는 조건 검색, 새로고침은 동일 조건 재검색, 내보내기는 현재 결과 저장입니다.
## 업무 흐름
기간 및 식별정보 입력 → 조회 → 결과·불량코드·RPM·Bit 확인 순서입니다.
## 입력 규칙 / 검증
시작일은 종료일보다 늦을 수 없습니다.
## 자주 묻는 질문
가공 조건 확인 시 같은 PID의 RPM과 Bit 값을 함께 비교합니다.

설비마스터
