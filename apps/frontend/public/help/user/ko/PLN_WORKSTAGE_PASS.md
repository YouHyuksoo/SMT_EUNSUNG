# 공정통과이력 관리

## 화면 목적

PID 또는 매거진 라벨을 스캔해 선택한 라인·공정의 통과 이력을 등록하거나 최근 등록을 취소하고, 공정별 이력과 재공 현황을 확인합니다.

## 화면 구성

- 스캔 영역: 라인, 공정, PID 스캔값, 취소, 재작업 허용
- 조회 조건: 모델명, 시리얼번호, 시작일, 종료일
- 조회 모드: 입고대기, 통과이력, 재공현황, 당일현황, 공정집계

## ① 조회 결과 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| 통과일시 / 출고일시 | 공정 입고 및 다음 공정 이동 시각 |
| PID/매거진 | 스캔한 제품 시리얼 또는 매거진 라벨 |
| RUN NO / 품목코드 | 생산 실행번호와 대상 품목 |
| 라인 / 공정 | 통과 처리한 생산 위치 |
| 모델명 / 서픽스 | 생산 모델 정보 |
| 수불 / 수량 | 입출고 구분과 처리 수량 |
| LOT NO | 연결된 생산 LOT |

재공현황은 기준일·공정·모델별 재공수량을, 공정집계는 공정·모델·수불구분별 수량을 표시합니다.

## 버튼별 기능

| 버튼 | 언제 사용 | 동작 | 결과 / 주의 |
|------|------|------|------|
| 통과등록 | 라인·공정 선택 후 PID 스캔 | 인터록과 PID 상태를 확인하고 공정통과 등록 | 중복 통과는 차단됩니다. |
| 통과취소 | 취소 체크 후 PID 스캔 | 확인창을 거쳐 현재 공정의 최근 통과 삭제 | 취소할 이력이 없으면 처리되지 않습니다. |
| 조회 / 새로고침 | 조회 조건 확인 후 | 선택한 조회 모드로 검색 | 로그인 조직 데이터만 표시합니다. |
| 내보내기 | 결과 저장 필요 시 | 현재 표를 파일로 저장 | 표의 필터 결과를 확인하세요. |

## 업무 흐름

1. 라인과 공정을 선택합니다.
2. 정상 통과는 PID/매거진 라벨을 입력하거나 스캔하고 Enter 또는 **통과등록**을 누릅니다.
3. 최근 통과를 되돌릴 때는 **취소**를 체크하고 스캔한 뒤 확인창의 **통과취소**를 누릅니다.
4. 재작업으로 동일 공정을 다시 통과시켜야 할 때만 **재작업 허용**을 체크합니다.
5. 조회 모드와 기간을 선택하고 **조회**로 결과를 확인합니다.

## 입력 규칙 / 검증

- 라인, 공정, PID는 필수입니다.
- 등록 전 공정 인터록과 PID 상태가 모두 정상이어야 합니다.
- 재작업 허용을 선택하지 않으면 같은 라인·공정의 중복 입고가 차단됩니다.
- 취소는 선택한 라인·공정에서 가장 최근에 등록된 입고 이력을 대상으로 합니다.

## 자주 묻는 질문

**스캔이 거부돼요.** 표시된 인터록 메시지, PID 등록 여부, 선택한 라인·공정을 확인하세요.

**조회는 되는데 등록이 안 돼요.** 조회 권한과 별개로 PID 상태 또는 중복 이력 검증에서 차단될 수 있습니다.
