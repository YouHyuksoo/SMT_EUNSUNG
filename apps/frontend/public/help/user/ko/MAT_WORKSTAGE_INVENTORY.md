# 공정재고조회

생산 공정에 남아 있는 품목별 재고수량을 조회하는 화면입니다. PowerBuilder `W_MAT_WORKSTAGE_INVENTORY_QUERY`의 조회 조건과 결과 항목을 기준으로 구성했습니다.

## 조회 방법

1. **품목**에서 전체 또는 특정 품목을 선택합니다.
2. 필요하면 **품목구분**(원자재·반제품·제품), **품목분류**(CAPACITOR, IC, PCB 등), **공급상**을 선택해 범위를 좁힙니다.
3. 수량이 0인 품목도 확인하려면 **0 재고 포함**을 선택합니다.
4. **조회**를 누릅니다.

## 조회 결과

품목코드, 품목구분, 품목분류, 품목명, 규격, 단위, 공급상코드·공급상명, 모델명, 자재위치, 공정재고수량, 등록·최종수정 정보를 확인할 수 있습니다. 품목구분부터 자재위치까지는 품목정보에 등록된 값입니다. 상단의 공정재고 합계는 현재 조회된 행의 수량 합계입니다.

## 제품(미입고 박스) 탭

포장은 했지만 아직 제품창고에 입고하지 않은 박스를 모델·품목별로 보여줍니다. 박스수, 포장수량, 최초·최종 포장일을 확인할 수 있습니다.

- 2026-10-01 이후 포장한 박스만 표시합니다. 출하된 박스는 빠집니다.
- 이 제품에 들어간 자재는 제품창고에 입고될 때 공정재고에서 빠집니다. 그래서 입고 전에는 **자재** 탭 수량에 그대로 포함돼 있습니다. 두 탭의 수량을 더하지 마십시오.
- 라인에 있는 반제품과 포장 전 제품은 수량 기록이 없어 표시하지 않습니다. 공정 실사에서 세어 반영합니다.

## 참고

- 품목 조건은 선택한 품목코드로 시작하는 데이터를 조회합니다.
- **0 재고 포함**을 해제하면 공정재고수량이 0보다 큰 데이터만 표시합니다.
- 표의 컬럼 필터와 내보내기 기능을 사용할 수 있습니다.
