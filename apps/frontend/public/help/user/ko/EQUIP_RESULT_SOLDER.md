# 솔더점도 검사결과조회
## 화면 목적
솔더 번호와 Lot별 점도 측정 이력을 확인합니다.
## 화면 구성
기간·라인·솔더 번호 조건과 결과 그리드가 있습니다.
## ① 결과 컬럼
측정일시, 라인, 설비, 솔더 번호, 솔더 Lot, RPM, 시간, 점도, 온도, 파일명, 등록일시, 등록자를 표시합니다.
## 버튼별 기능
조회·새로고침·내보내기를 지원합니다.
## 업무 흐름
기간과 솔더 번호 입력 → 조회 → 점도·온도·RPM 확인 순서입니다.
## 입력 규칙 / 검증
기간 역전은 허용되지 않으며 솔더 번호는 부분 일치합니다.
## 자주 묻는 질문
동일 Lot 비교 시 솔더 Lot 열로 필터링합니다.
## 관련 화면
SP 작업결과조회
